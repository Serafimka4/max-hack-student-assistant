# platform

Laravel-приложение проекта. Описание, запуск и учётные записи — в [корневом README](../README.md).

Устройство кода:

- `app/Actions` — предметная логика, общая для API и админ-панели (версии шаблонов и тестов, публикация).
- `app/Policies` — права участников организаций.
- `app/Http/Controllers/Api/V1`, `app/Http/Resources/V1` — REST API.
- `app/Filament` — админ-панель, кабинет на каждую организацию.
- `app/Support/Max` — проверка данных запуска мини-приложения MAX.
